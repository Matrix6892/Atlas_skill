# Атлас

**Память и карта проекта, которую ведёт агент, а читает человек.** Скилл и плагин для Claude Code, собранный по ТЗ «Атлас» v0.7 ([docs/Atlas_TZ_v0_7.md](docs/Atlas_TZ_v0_7.md)).

Агент работает как обычно, но после значимых шагов оставляет короткие записи: что сделано, что решено, что проверено, что отложено. Из записей ядро **без модели** собирает для владельца короткий доклад при входе, список «Нужно от вас», карточку результата с тремя строками доверия («сказано · проверено · принято») и закладку «на сегодня всё».

> **Статус.** Это реализация **этапа M0** («одна тема, один цикл, всё в чате», §8.2 ТЗ), предназначенная для пилота. Интервью и пилот, которые ТЗ требует до следующих этапов (§8.1), ещё не проводились, поэтому пользу Атласа это не доказывает. Протокольные проверки из Приложения G, относящиеся к M0, покрыты автоматическими тестами. Связка «хуки → скилл → ядро» проверена тремя короткими живыми прогонами Claude Code на учебном проекте (что найдено и исправлено — в [docs/M0-решения.md](docs/M0-решения.md)).

## Что умеет этап M0

| Экран ТЗ | Как вызвать (голосом или фразой) | Кто строит |
| --- | --- | --- |
| Э0. Доклад при входе | сам при старте сессии; «где мы?» | ядро |
| Э3. «Нужно от вас» | «что от меня нужно?» | ядро; варианты и совет — агент |
| Э4. Карточка результата | «покажи, что готово» | ядро; инструкцию проверки пишет агент |
| Э5. «Как я понял» | надиктовка из нескольких мыслей | агент |
| Э6. Договорённость о задании | перед заданием с риском | агент предлагает, ядро записывает |
| Э7. Закладка и итог | «на сегодня всё» | ядро; «узнали / не получилось» — агент |
| Э9. Первый запуск | «подключи Атлас» | ядро — установка, агент — разбор одной темы |
| Э11. «Ты неверно понял» | «ты неверно понял», «это не решение» | агент понимает, ядро пишет исправление |
| Э2 кратко, в чате | «что с входом?» | ядро |
| Э8 порцией, в чате | «давай разберём идеи» | ядро; «связано с целью» — агент |
| главная в чате | «покажи всё» | ядро (HTML-страницы — этап M1) |

Правила ТЗ, которые соблюдает само ядро, а не только агент:

- решение, приёмка, договорённость, отпускание темы записываются **только со словами владельца** (молчание — не согласие);
- «проверил» и «принимаю» — разные записи; приёмка относится к конкретной версии, условиям и цели;
- «проверено тестом» ставится только за запуск, который ядро видело само (`atlas.py check`); слова агента «тесты прошли» остаются «со слов агента»;
- «мы же решили…» не создаёт второго такого же решения;
- одно решение — одна карточка; временный выбор агента запрещён, если затронуты деньги, публикация или настоящие данные;
- в работе не больше трёх тем без явного согласия владельца;
- повтор квитанции ничего не удваивает; конфликт версий и повреждённая запись видны, поверх них ничего не пишется;
- неполная запись прошлой сессии называется первой строкой доклада, с причиной;
- секреты не записываются; попавшее чувствительное удаляется с честным перечнем того, что удалить нельзя;
- личное («как прошло?») хранится только локально и не попадает в git, экспорт и сводку агенту.

## Установка

Нужен **Python 3.8 или новее**. Хватает стандартной библиотеки, сторонних пакетов нет. Git желателен: без него версии результатов нельзя привязать к состоянию кода, и Атлас прямо об этом говорит.

### Вариант 1. Плагин (рекомендуется)

В Claude Code:

```
/plugin marketplace add Matrix6892/Atlas_skill
/plugin install atlas@atlas-marketplace
```

Хуки плагина срабатывают только в проектах, где Атлас подключён. В остальных они ничего не делают.

### Вариант 2. Только скилл

Скопируйте папку `skills/atlas` в `~/.claude/skills/atlas`. При подключении к проекту Атлас сам добавит два хука в `.claude/settings.local.json` (личные настройки проекта).

### Подключение к проекту

В сессии Claude Code внутри проекта скажите: **«подключи Атлас»**. Агент выполнит `atlas.py connect` и покажет, что изменено:

```text
Атлас подключён к «Заметки для друзей».
Изменил:    создал папку .atlas/ (записи, настройки; личное — в .atlas/.local/, в git не попадает).
            создал файл и добавил блок Атласа в CLAUDE.md (инструкции агента).
            добавил два хука (события, на которые агент вызывает Атлас) …: старт сессии и конец ответа.
Не трогал:  код, ваши инструкции вне блока Атласа, настройки git.
```

Затем агент спросит, с какой темой сейчас больше всего неясности. Первая польза — ответ по одной теме, без разбора всего проекта.

«Отключи Атлас» убирает только блок в CLAUDE.md и свои хуки. Данные остаются в `.atlas/`, экспорт в обычный файл делает `atlas.py export`.

## Как это выглядит

Доклад при входе показывается сам, до первого ответа агента:

```text
Заметки для друзей · закладка от четверга, 24 сентября, 22:10
Цель: Друг сам создаёт первую заметку, без моей помощи
Где остановились: вход через Google — входит и видит имя, проверено тестом на компьютере
После закладки:   других сессий не было.
Нужно от вас:     проверить и принять вход через Google (версия r7);
                  куда вести после входа: в профиль или на главную? (вопрос 4)

Предлагаю: проверить вход через Google (версия r7) самому, около пяти минут, включая запуск; инструкция готова.
Скажите «давай», «другое» или «покажи всё».
```

Карточка результата:

```text
РЕЗУЛЬТАТ · Вход через Google (версия r7 — номер растёт при каждой переделке; предъявлен в четверг, 24 сентября)
Что сделано: человек входит через Google и видит своё имя в профиле
Не входит:   вход с телефона, показ ошибок входа.
Сказано агентом · проверено 1 из 2, тестом на компьютере · не принято
Годится для показа другу с вашего компьютера; для настоящих пользователей — нет.
Оговорки: только тестовые данные; куда вести после входа: в профиль или на главную — временный выбор агента, ждёт вашего ответа (вопрос 4).

КАК ПРОВЕРИТЬ САМОМУ (около пяти минут, включая запуск)
  0. Скажите агенту «запусти проект» — он откроет страницу сам.
  1. Нажмите «Войти через Google» и выберите свой аккаунт.
  2. Должно быть: страница профиля, вверху ваше имя. Провал: белый экран или снова страница входа.
Скажите «проверил, работает», «не работает: …» или «принимаю для показа».
```

## Где что лежит

```text
.claude-plugin/        манифест плагина и маркетплейса
hooks/hooks.json       хуки плагина: старт сессии и конец ответа
skills/atlas/
  SKILL.md             инструкция агенту
  references/          квитанции (все операции записи), экраны агента и правила письма, фразы владельца
  scripts/atlas.py     ядро: единственная точка записи и экраны
  scripts/atlaskit/    модули ядра (store, state, ops, views, brief, hooks, install, cli)
tests/                 автоматические проверки (unittest)
docs/                  ТЗ v0.7 и решения этапа M0
```

В проекте владельца (по Приложению E.7 ТЗ):

```text
.atlas/
  atlas.config.json    общая конфигурация
  data/records/        канонические записи: одна транзакция — один JSON-файл
  .local/              только на этом компьютере: манифесты сессий, личное, блокировки
```

## Команды ядра

Обычно их вызывает агент. Полный список показывает `python3 skills/atlas/scripts/atlas.py --help`.

`connect`, `disconnect`, `changes` · `report` (Э0), `overview` («покажи всё»), `needs` (Э3), `result` (Э4), `topic` (Э2), `parking` (Э8), `decisions`, `find` · `write` — единственная точка записи (квитанция JSON) · `check` — наблюдаемый запуск проверки · `brief` — сводка агенту · `start` — ручной режим для Codex и других агентов без хуков · `mood`, `prefs`, `rules`, `scan`, `export`, `redact`, `doctor`.

## Что сознательно не сделано на M0

По §8.2 ТЗ это следующие этапы, и Атлас не изображает, что они есть:

- **M1:** HTML-страницы (главная, темы, парковка), экран «Что изменилось» (Э10), адаптер Codex с хуками, параллельные сессии с разрешением конфликтов, сверка карты с кодом.
- **M2:** «Темп и цена» (Э12), наблюдения живых людей, прямые действия с кнопок, разбор всего проекта, пакет передачи.
- **M3:** личные функции — только после явного спроса.

Договорённость о задании пока **рекомендательная**. Ядро защищает свои записи, но не может остановить команды агента вне Атласа (C.4 ТЗ). Это сказано владельцу при подключении.

## Разработка

```bash
cd tests && python3 -m unittest -v
```

Тесты проходят на Python 3.8, 3.10, 3.11, 3.12 и 3.13.
