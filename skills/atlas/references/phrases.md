# Фразы владельца и что они значат (§5.14 ТЗ)

Фразы — только примеры: смысл понимается в любой форме. Для действий с последствиями повтори смысл целиком, а не только номер: «Принимаете вход через Google, версия r7, для показа другу?» Если поручение ясное, объект точный и риск низкий, повторное подтверждение не нужно.

| Владелец говорит | Что сделать |
| --- | --- |
| «Где мы?», «что там с проектом?» | `atlas report`, показать как есть |
| «Покажи всё» | `atlas overview` |
| «Что с входом?» | `atlas topic "Вход"` |
| «В сторону: экспорт в PDF», «запиши идею…» | `park.add`, текущую тему не менять и идею не обсуждать |
| «Забрось», «убери», «отпусти» | Для темы — `thread.state` → `released` с причиной; для записи парковки — `park.release` |
| «В следующий спринт», «следующим» | Для темы — `thread.state` → `planned`; для идеи — `park.promote` с `to: planned` |
| «Берём», «давай в работу» | `thread.state` → `active` (с учётом лимита тем) или `park.promote` с `to: active` |
| «На паузу, жду дизайн» | `thread.state` → `paused`, причина — «жду дизайн» |
| «Заморозь» | `thread.state` → `frozen` |
| «Да, это тема» / «это не тема» | Кандидата — в `planned` или `active` / в `released` с причиной «не тема» |
| «Что от меня нужно?» | `atlas needs` |
| «Покажи, что готово» | `atlas result` |
| «Запусти проект» | Запусти сам и открой страницу. Владелец код не запускает |
| «Проверил, работает» | `verify`: `owner_manual`, `passed`, слова владельца. Это ещё **не** приёмка |
| «Не работает: белый экран» | `verify`: `owner_manual`, `failed`, `detail`. Тема возвращается в работу |
| «Не смог запустить» | `verify`: `could_not_check`, затем помочь подготовить запуск. Провал не записывается |
| «Принимаю для показа» | `accept`: `accepted`, `purpose: "показа"`, слова владельца |
| «Принимаю, но кнопка мелкая» | `accept`: `accepted_with_caveat`, `caveat` |
| «Не принимаю: кнопка не там, где договаривались» | `accept`: `rejected`, `rejection.class` (дефект / новое пожелание / среда / ошибка инструкции) |
| «Проверил, работает, но дизайн не принимаю» | Две операции: `verify` passed и `accept` rejected |
| «Пусть проверит кто-то ещё» | Поручение на независимую проверку: что проверить и в каком бюджете |
| «После входа — в профиль» = «вопрос 4 — А» | `decision.decide` с `option`, `text` («После входа ведём в профиль») и словами владельца. Повтори смысл целиком |
| «Реши сам» | `decision.delegate`, затем `decision.decide` с `delegated: true`. Не для денег, публикации и настоящих данных |
| «Нужно больше данных» | Предложи, как быстро выяснить; вопрос остаётся |
| «Позже» | `decision.defer`: вопрос остаётся; молчание не станет согласием |
| «Не спрашивай такое» | `rule.propose`; правило действует только после `rule.confirm` |
| «Мы же решили…» | `atlas find …`. Новое решение **не** создавать |
| «Решение про телефон больше не действует» | `decision.supersede`, новый текст и слова владельца |
| «Что изменилось?», «стало лучше или хуже?» | Экран Э10 относится к этапу M1 и пока не построен. Честно скажи об этом; можно показать `atlas topic` по затронутым темам |
| «Ты неверно понял», «это не решение», «это не та тема» | Экран Э11, после «да» — `correct` |
| «Давай разберём идеи» | `atlas parking`, ответ пакетом — независимыми операциями |
| «На сегодня всё», «подведи итог», «сохрани, где мы» | `bookmark.save`, затем показать экран, который вывел `write` |
| «Тяжело» / «нормально» / «в кайф» / «пропустить» | `atlas mood …`, только локально. «Не спрашивай» отключает вопрос |
| «Да», «первое», «всё» | Допустимы только при однозначном ближайшем предложении; иначе уточни |
| «Прими всё, кроме оплаты» | Покажи точную область приёмки перед записью |
| «Я устал от этого входа» | Это эмоция, а не задача. Можно предложить паузу; тему не удалять |
| «Отключи Атлас» | `atlas disconnect`; данные остаются |
| «Экспортируй» | `atlas export` |
| «Удали это из Атласа» (секрет) | `atlas redact <ID>`: показать план; только после «да» — `--confirm` |
